# Turtle Crossing Game

A classic Turtle Crossing game developed using Python and the Turtle graphics module. Guide the turtle across the road while avoiding moving cars. Each successful crossing increases the difficulty by increasing car speed and spawn frequency.

## Features

- Keyboard-controlled turtle movement
- Randomly generated cars with different colors
- Collision detection between the player and cars
- Progressive difficulty with increasing levels
- Score and level tracking
- Game-over screen with a restart option

## Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)

## Controls

| Key | Action |
|---|---|
| Up Arrow | Move the turtle forward |
| W | Move the turtle forward |

## Getting Started

### Prerequisites

- Python 3 installed on your system
- Tkinter support for Turtle graphics

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/cherry-achyuth/turtle-crossing-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd turtle-crossing-game
   ```

3. Run the game:

   ```bash
   python main.py
   ```

## How to Play

1. Start the game and control the turtle using the keyboard.
2. Cross the road while avoiding the moving cars.
3. Reach the opposite side to advance to the next level.
4. Avoid collisions to continue playing.
5. If a collision occurs, choose whether to restart or exit.
